# پروژه ۵ — رسم چگال قلب با import * از turtle

## توضیح
این نسخه از واسط رویه‌ای کامل `turtle` با `from turtle import *` استفاده می‌کند، به همین دلیل توابعی مثل `goto`, `speed`, `bgcolor`, `color`, `done` بدون پیشوند فراخوانی می‌شوند.

توابع `heart(k)` و `heart1(k)` مقادیر x و y مسیر قلب را برمی‌گردانند. حلقه‌ی اصلی به‌جای تقسیم دایره به بازه‌ی ۰ تا ۲π، مقدار `i` را مستقیماً (بدون تبدیل به رادیان استاندارد بین ۰ تا ۲π) به این توابع می‌دهد و تا ۶۰۰۰ بار تکرار می‌کند. چون توابع `sin`/`cos` تناوبی‌اند، این باعث می‌شود مسیر قلب بارها و بارها روی هم رسم شود و طرحی چگال و پرتراکم (شبیه گلوله‌های نخ روی هم) به‌جای یک خط تمیز ایجاد شود.

حلقه‌ی داخلی `for j in range(5): color("purple")` صرفاً رنگ قلم را ۵ بار پشت‌سرهم روی بنفش تنظیم می‌کند و در عمل تاثیری در ظاهر ندارد؛ چون هیچ حرکتی بین این تکرارها انجام نمی‌شود. کد را دقیقاً مطابق تصویر ارسالی نگه داشتم و تغییری در منطق آن ندادم.

## پیش‌نیازها
- پایتون ۳ (ماژول‌های `turtle`, `math` استاندارد هستند)
- در لینوکس در صورت نیاز: `sudo apt-get install python3-tk`

## اجرا
```bash
python3 heart_drawing.py
```

## سفارشی‌سازی
- عدد `20` (ضریب مقیاس در `goto`) اندازه‌ی کلی طرح را تغییر می‌دهد.
- `range(6000)` تعداد تکرار و چگالی نهایی طرح را کنترل می‌کند؛ عدد کمتر یعنی طرح شفاف‌تر و کم‌چگال‌تر.
- برای رسم یک قلب تمیز و استاندارد (به‌جای طرح چگال)، بهتر است `i` را به رادیان استاندارد تبدیل کنید، مثلاً: `angle = 2 * math.pi * i / 6000`.
