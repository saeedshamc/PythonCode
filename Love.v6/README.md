# پروژه ۴ — قلب با خطوط شعاعی رو به بیرون (افکت انفجاری)

## توضیح
تابع `heart(t)` مختصات مسیر قلب را برمی‌گرداند. برای هر نقطه از مسیر (`hx, hy`)، یک نقطه‌ی «بیرونی‌تر» با ضریب بزرگ‌نمایی `K` محاسبه می‌شود (`ex, ey`). سپس از نقطه‌ی روی مسیر تا نقطه‌ی بیرونی، ۱۴ گام (`steps`) رسم می‌شود که رنگ آن از قرمز روشن (`bright`) به قرمز تیره‌ی نزدیک به سیاه (`dark`) تغییر می‌کند. حاصل، شکلی شبیه قلبی با خطوط نورانی رو به بیرون (مثل تاج نور) است.

توجه: نام پارامتر تابع `heart` عمداً `t` است (مطابق تصویر اصلی) و با متغیر سراسری `t` (شیء Turtle) تداخلی ندارد، چون در پایتون این پارامتر فقط داخل بدنه‌ی همان تابع معتبر است.

## پیش‌نیازها
- پایتون ۳ (ماژول‌های `turtle`, `math` استاندارد هستند)
- در لینوکس در صورت نیاز: `sudo apt-get install python3-tk`

## اجرا
```bash
python3 heart_drawing.py
```

## سفارشی‌سازی
- `SCALE` اندازه‌ی کلی قلب را تعیین می‌کند.
- `K` هرچه بزرگ‌تر باشد، خطوط شعاعی بلندتر و پخش‌شده‌تر می‌شوند.
- `N` تراکم خطوط دور قلب و `steps` تعداد نقاط گرادیان روی هر خط را کنترل می‌کند.
- رنگ‌های `bright` و `dark` را تغییر دهید تا افکت رنگی دیگری بگیرید.
