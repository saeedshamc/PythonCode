# پروژه ۱ — قلب با خطوط انیمیشنی رو به داخل

## توضیح
این اسکریپت با استفاده از واسط رویه‌ای (procedural) ماژول `turtle` (با نام مستعار `t`)، روی مسیر معادله‌ی پارامتریک قلب حرکت می‌کند. برای هر نقطه از مسیر بیرونی قلب، یک نقطه‌ی داخلی تصادفی (با ضریب کوچک‌سازی تصادفی `L`) محاسبه می‌شود و سپس با ۱۰ گام رنگی متغیر (از صورتی روشن به سمت تیره‌تر)، یک خط کوتاه بین این دو نقطه رسم می‌شود. نتیجه، افکتی شبیه به «رگه‌های نوری» است که رو به داخل قلب کشیده می‌شوند.

از `screen.tracer(0)` و `screen.update()` برای کنترل دستی سرعت رندر و ایجاد انیمیشن روان استفاده شده است.

## پیش‌نیازها
- پایتون ۳ (ماژول‌های `turtle`, `math`, `random`, `time` همگی استاندارد هستند)
- در لینوکس در صورت نیاز: `sudo apt-get install python3-tk`

## اجرا
```bash
python3 heart_drawing.py
```

## سفارشی‌سازی
- عدد `16` (ضریب مقیاس) را برای بزرگ/کوچک کردن قلب تغییر دهید.
- بازه‌ی `r.uniform(0.15, 0.5)` میزان تصادفی بودن عمق خطوط را کنترل می‌کند.
- `time.sleep(0.02)` سرعت انیمیشن را تنظیم می‌کند؛ عدد کوچک‌تر یعنی سریع‌تر.
