# Geometric Flower (turtle)

نسخه‌ی تایپ‌شده و بررسی‌شده‌ی کدی که در عکس فرستادید.

## نتیجه‌ی بررسی
برخلاف چند مورد قبلی، این عکس **کامل** بود و چیزی از کد بریده/جا نیفتاده بود — از `import turtle` تا خط آخر (`s.mainloop()`) همه‌چیز موجود بود و از نظر نحوی (syntax) هم درست است؛ با `ast.parse` تست شد و مشکلی نداشت. فقط عین همان چیزی که در تصویر بود را تایپ کردم، بدون هیچ تغییری در منطق.

## پیش‌نیازها
- پایتون ۳ (ماژول `turtle` استاندارد است)
- در لینوکس در صورت نیاز: `sudo apt-get install python3-tk`

## اجرا
```bash
python3 geometric_flower.py
```

با اجرای کد یک پنجره‌ی مشکی باز می‌شود و یک الگوی هندسی گل‌مانند از دایره‌های رنگی رسم می‌شود. چون از `s.mainloop()` به‌جای `s.exitonclick()` استفاده شده، پنجره تا زمانی که خودتان آن را ببندید باز می‌ماند (نیازی به کلیک کردن روی صفحه نیست).

## توضیح منطق کد
- `colors`: چهار رنگ که به‌ترتیب برای هر «لایه» از الگو استفاده می‌شوند.
- حلقه‌ی بیرونی (`for n in range(5)`): پنج لایه‌ی متفاوت رسم می‌کند؛ هر لایه شعاع بزرگ‌تری دارد (`80 + n*20`) و رنگش با `colors[n % 4]` چرخشی انتخاب می‌شود.
- حلقه‌ی میانی (`for x in range(8)`): در هر لایه، ۸ بار یک جفت نیم‌دایره رسم می‌کند و بعد از هر بار، ۴۵ درجه می‌چرخد؛ همین چرخش تدریجی باعث ایجاد الگوی متقارن گل‌مانند دور یک نقطه می‌شود.
- حلقه‌ی داخلی (`for i in range(2)`): برای هر گلبرگ، دو نیم‌دایره (هرکدام با `circle(radius, 90)` یعنی یک‌چهارم دایره) پشت‌سرهم با چرخش ۹۰ درجه‌ای رسم می‌کند که شکل یک گلبرگ کوچک می‌سازد.

## سفارشی‌سازی
- برای رنگ‌های متفاوت، مقادیر داخل `colors` را عوض کنید.
- `range(5)` در حلقه‌ی بیرونی تعداد لایه‌ها و `80 + n*20` فاصله‌ی شعاعی بین لایه‌ها را کنترل می‌کند.
- `range(8)` و `p.left(45)` تعداد گلبرگ‌ها دور هر لایه را مشخص می‌کنند (۳۶۰ ÷ ۴۵ = ۸ گلبرگ)؛ برای گلبرگ‌های بیشتر/کمتر هر دو عدد را هماهنگ تغییر دهید (مثلاً ۱۲ گلبرگ با `range(12)` و `p.left(30)`).
- `p.speed(10)` سرعت رسم را تنظیم می‌کند؛ عدد بزرگ‌تر یعنی سریع‌تر (حداکثر ۱۰، یا `0` برای سریع‌ترین حالت ممکن).
