# رسم قلب با Turtle (پایتون)

این اسکریپت با استفاده از ماژول `turtle` یک شکل قلب رنگی و انیمیشنی روی صفحه رسم می‌کند. برای هر نقطه از مسیر قلب، یک ستاره‌ی کوچک (با استفاده از حرکت رفت‌وبرگشت و چرخش) با رنگ تصادفی کشیده می‌شود.

## پیش‌نیازها

- پایتون نسخه ۳ (ترجیحاً ۳.۸ به بالا)
- ماژول‌های `turtle`، `math` و `random` — هر سه جزو کتابخانه‌ی استاندارد پایتون هستند و نیازی به نصب جداگانه ندارند.

> نکته: در برخی سیستم‌عامل‌های لینوکسی، ماژول `turtle` به‌صورت پیش‌فرض نصب نیست. در این صورت با دستور زیر آن را نصب کنید:
> ```
> sudo apt-get install python3-tk
> ```

## نحوه‌ی اجرا

فایل `heart_drawing.py` را در همان پوشه قرار دهید و دستور زیر را در ترمینال اجرا کنید:

```bash
python3 heart_drawing.py
```

پس از اجرا، یک پنجره‌ی گرافیکی با پس‌زمینه‌ی مشکی باز می‌شود و شکل قلب به‌تدریج با رنگ‌های مختلف رسم می‌شود.

برای بستن پنجره، کافی است روی آن کلیک کنید یا پنجره را ببندید.

## توضیح کد

- **`screen` و `t`**: به‌ترتیب صفحه‌ی گرافیکی و قلم (Turtle) هستند. رنگ پس‌زمینه مشکی و سرعت قلم روی حداکثر (`speed(0)`) تنظیم شده تا رسم سریع انجام شود.
- **حلقه‌ی اصلی (`for i in range(120)`)**: صفحه را به ۱۲۰ نقطه تقسیم می‌کند و برای هر نقطه، مختصات آن روی منحنی قلب را با فرمول‌های ریاضی زیر محاسبه می‌کند:
  - `x = 16 * sin(angle)^3 * 15`
  - `y = (13*cos(angle) - 5*cos(2*angle) - 2*cos(3*angle) - cos(4*angle)) * 15`

  این فرمول همان «معادله‌ی پارامتریک قلب» معروف است که در ریاضیات برای رسم شکل قلب استفاده می‌شود.
- **رنگ تصادفی**: در هر نقطه، یک رنگ تصادفی از لیست `colors` انتخاب می‌شود.
- **حلقه‌ی داخلی (`for _ in range(8)`)**: در هر نقطه از مسیر قلب، یک الگوی ستاره‌مانند کوچک با حرکت رفت (`forward`) و برگشت (`backward`) و چرخش ۴۵ درجه‌ای (`right(45)`) رسم می‌کند که باعث ایجاد جلوه‌ی تزئینی می‌شود.
- **`turtle.done()`**: پنجره را باز نگه می‌دارد تا نتیجه قابل مشاهده باشد.

## سفارشی‌سازی

- برای تغییر اندازه‌ی قلب، عدد `15` که در محاسبه‌ی `x` و `y` ضرب شده را تغییر دهید.
- برای رنگ‌های دیگر، لیست `colors` را ویرایش کنید.
- برای تغییر تراکم نقاط مسیر، عدد `120` در `range(120)` را کم یا زیاد کنید.
- برای تغییر شکل الگوی تزئینی هر نقطه، مقادیر `forward`، `backward` و `right` در حلقه‌ی داخلی را تغییر دهید.
