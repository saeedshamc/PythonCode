# Heart Stars Animation

انیمیشنی با کتابخانه `turtle` که ۵۰۰ ستاره‌ی پراکنده روی صفحه را به‌تدریج در قالب یک شکل قلب (با فرمول پارامتریک قلب) کنار هم می‌چیند.

## نحوه‌ی اجرا

```bash
python heart_stars.py
```

نیازی به نصب پکیج اضافه نیست؛ `turtle`، `math`، `random` و `time` همگی بخشی از کتابخانه‌ی استاندارد پایتون هستند (روی لینوکس ممکن است لازم باشد `python3-tk` را نصب کنید: `sudo apt install python3-tk`).

## نحوه‌ی کار کد

1. **تولید موقعیت‌ها (خطوط ۸ تا ۲۱)**
   - `N = 500` ستاره تعریف می‌شود.
   - برای هر ستاره، یک نقطه‌ی مقصد روی منحنی پارامتریک قلب محاسبه می‌شود:
     - `base_x = 16·sin³(a)`
     - `base_y = 13·cos(a) − 5·cos(2a) − 2·cos(3a) − cos(4a)`
   - کمی نویز تصادفی (`uniform(-15, 15)`) به مقصد اضافه می‌شود تا شکل قلب صاف و مصنوعی به نظر نرسد.
   - موقعیت شروع هر ستاره کاملاً تصادفی روی صفحه انتخاب می‌شود.

2. **رسم هر ستاره (`draw_star`)**
   - هر ستاره با ۴ خط متقاطع (در زوایای ۰، ۴۵، ۹۰، ۱۳۵ درجه) به رنگ بنفش (`#a855f7`) رسم می‌شود؛ شبیه یک ستاره‌ی چهارپَر ساده.

3. **انیمیشن (خطوط ۳۵ تا ۴۷)**
   - در ۵۰ فریم، هر ستاره از موقعیت شروع به موقعیت مقصد حرکت می‌کند.
   - از تابع `sin(progress·π/2)` به‌عنوان easing استفاده شده تا حرکت در پایان کندتر و نرم‌تر شود (ease-out).
   - `screen.tracer(0)` و `screen.update()` با هم باعث می‌شوند فریم‌ها یکجا رندر شوند، نه لحظه‌به‌لحظه.

## تنظیمات قابل تغییر

| متغیر | توضیح |
|---|---|
| `N` | تعداد ستاره‌ها |
| `steps` | تعداد فریم‌های انیمیشن (بیشتر = نرم‌تر و کندتر) |
| `time.sleep(0.025)` | تأخیر بین فریم‌ها (کمتر = سریع‌تر) |
| `"#a855f7"` | رنگ ستاره‌ها |
| `s.setup(600, 600)` | ابعاد پنجره |
