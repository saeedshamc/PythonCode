# پروژه ۲ — انیمیشن ستاره‌ها که به شکل قلب جمع می‌شوند

## توضیح
این اسکریپت ابتدا ۵۰۰ «ستاره» (نقطه‌ی چهارپَر) را در موقعیت‌های کاملاً تصادفی روی صفحه قرار می‌دهد (`sx, sy`). سپس برای هر ستاره یک موقعیت مقصد (`tx, ty`) روی مسیر معادله‌ی پارامتریک قلب (با کمی پراکندگی تصادفی) تعیین می‌کند.

در ۵۰ فریم متوالی، موقعیت هر ستاره با یک تابع نرم‌کننده (`easing`) بر پایه‌ی `sin` به‌تدریج از نقطه‌ی شروع به‌سمت نقطه‌ی مقصد حرکت می‌کند، به‌طوری‌که در نهایت تمام ستاره‌ها شکل یک قلب بنفش‌رنگ را می‌سازند. تابع `draw_star` هر ستاره را با چهار خط متقاطع (شبیه ستاره‌ی چهارپَر) رسم می‌کند.

## پیش‌نیازها
- پایتون ۳ (ماژول‌های `turtle`, `math`, `random`, `time` استاندارد هستند)
- در لینوکس در صورت نیاز: `sudo apt-get install python3-tk`

## اجرا
```bash
python3 heart_drawing.py
```

## سفارشی‌سازی
- `N = 500` تعداد ستاره‌ها را مشخص می‌کند؛ عدد بیشتر یعنی قلب پرتراکم‌تر ولی اجرای کندتر.
- رنگ ستاره‌ها را با تغییر `"#a855f7"` در `draw_star` عوض کنید.
- `steps = 50` و `time.sleep(0.025)` سرعت و نرمی انیمیشن را کنترل می‌کنند.
- بازه‌های `r.uniform(-15, 15)` پراکندگی نقاط مقصد دور مسیر قلب را تعیین می‌کنند.
